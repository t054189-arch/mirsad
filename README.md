# مِرصاد · MIRSAAD

> **نفحص اليوم .. لنبني غدًا أكثر أمانًا**
> SAFER STRUCTURES · BRIGHTER TOMORROW


**منصة ذكية وآمنة مخصصة للمكاتب الهندسية**، تساعد المهندسين على إدارة ومتابعة عمليات فحص المنشآت والبنية التحتية.

بدل أن تكون كل عملية فحص عبارة عن مجموعة منفصلة من الصور والتقارير والملفات، تجمع مرصاد بيانات المنشأة في **سجل رقمي مستمر**.

يقوم المهندس بإدخال بيانات الفحص ورفع الصور والملاحظات والتقارير، ثم يعمل الـAI Agent على تحليل البيانات، والبحث في تاريخ المنشأة، ومقارنة الفحص الحالي بالفحوصات السابقة، وتحديد الـFindings التي تحتاج إلى مراجعة المهندس.

بعد مراجعة المهندس، تُحفظ النتائج في سجل المنشأة، وتصبح هذه المعلومات جزءًا من تاريخ المنشأة الذي سيستخدمه الـAgent في الفحص القادم.

> مرصاد ليست مجرد أداة لاكتشاف التشققات، وليست مجرد Chatbot، وإنما **نظام كامل لإدارة دورة فحص المنشأة بشكل مستمر**.

## رحلة المستخدم

من إدخال البيانات إلى الإشعار النهائي — تسع خطوات، معروضة في الموقع مع واجهة مصغّرة لكل خطوة.

| # | الخطوة | ماذا يحدث |
|---|--------|-----------|
| 1 | تسجيل الدخول | يدخل المستخدم إلى حسابه في مرصاد |
| 2 | اختيار المنشأة | يختار المنشأة المراد فحصها أو ينشئ منشأة جديدة |
| 3 | إدخال بيانات الفحص | نوع الفحص والتاريخ والقياسات والملاحظات |
| 4 | رفع الملفات | الصور والتقارير والملفات المرتبطة بالزيارة |
| 5 | بدء التحليل | الوكيل الذكي يحلل البيانات ويقارنها بالسجل السابق |
| 6 | عرض النتائج | الملاحظات المحتملة مرتبةً حسب الأولوية |
| 7 | مراجعة المستخدم | المهندس يوافق أو يرفض أو يعدّل |
| 8 | تحديث السجل | يُحفظ القرار في سجل المنشأة |
| 9 | إشعار من الوكيل الذكي | إشعار بنتيجة المراجعة وبما يحتاج إجراءً إضافيًا |

ما يُحفظ في الخطوة ٨ هو ما يقرأه الوكيل في الخطوة ٥ من الفحص القادم — الرحلة **دورة لا خط مستقيم**.

## الهوية والثيمات

**الهوية الرسمية** مأخوذة من لوحة هوية المشروع: فحمي دافئ `#181613` + رملي `#ead5b8`،
مع شعار القُبّة (سبعة أقواس تتفرّع من نقطة واحدة) وقفل نصي ثنائي اللغة `مرصاد / MIRSAAD`.

تُبدَّل الثيمات من زر **الثيم** في الشريط العلوي، ويُحفظ الاختيار في `localStorage`.
كل ثيم مجموعة متغيرات CSS تحت `[data-theme="..."]` — لا يوجد أي كود مكرر.

| الثيم | `data-theme` | اللوحة | الاستخدام |
|-------|--------------|--------|-----------|
| **مرصاد** (الافتراضي) | `mirsaad` | فحمي دافئ `#181613` + رملي `#ead5b8` | الهوية المعتمدة — هي الثيم الذي يفتح به الموقع |
| **كِنتسوغي** | `kintsugi` | خزف دافئ `#f7f3ec` + ذهب `#916118` | بديل فاتح بنفس الدفء؛ الشرخ المُعالج يُبرَز لا يُخفى |
| **فجر** | `dawn` | نيلي عميق `#121729` + كهرماني `#ffa552` | بديل داكن أبرد — أول ضوء على الموقع |
| **أُفق** | `horizon` | سماوي فاتح `#f3f7fb` + أزرق `#0b6fbd` | للعروض والطباعة النهارية |
| **ترميم** | `restored` | أخضر مائي داكن `#0e1a19` + نعناعي `#62dcae` | ما بعد المعالجة واستعادة السلامة |

كل أزواج النص/الخلفية تتجاوز نسبة تباين 4.5:1 في الثيمات الخمسة.

### عناصر الهوية في التصميم

- **الشعار** قُبّة من سبعة أقواس، تُرسَم قوسًا بعد قوس عند فتح الصفحة.
- **خط الأفق** رسم متجهي لجسر جابر أسفل الواجهة، بلون الثيم ويتلاشى للأعلى.
- **الدرز المُرمَّم** بين الأقسام: خط مستقيم يمثّل الحافة الأصلية يعلوه خط يحيد عنه — أي الترميم — ويُرسَم عند التمرير.
- **الواجهات المصغّرة** داخل خطوات الرحلة مبنية بـHTML/CSS فقط، لا صور، فتتبدّل ألوانها مع الثيم.

### تغيير الثيم الافتراضي

عدّل قيمة `data-theme` على وسم `<html>` في `index.html`:

```html
<html lang="ar" dir="rtl" data-theme="dawn">
```

### إضافة ثيم جديد

أضف كتلة متغيرات في `assets/style.css`، ثم زرًا في قائمة `.themes` داخل `index.html` بالسمة `data-theme-set="اسم-الثيم"`:

```css
[data-theme="my-theme"]{
  --bg: …; --bg-alt: …; --surface: …; --surface-2: …;
  --ink: …; --ink-soft: …; --line: …;
  --accent: …; --accent-deep: …; --accent-soft: …; --on-accent: …;
  --hi: …; --mid: …; --ok: …;      /* حالات الملاحظات */
  --grid-ink: …; --shadow: …; --mark-strength: …;
  color-scheme: light | dark;
}
```

## البنية

```
index.html          صفحة المشروع (عربية، RTL)
assets/style.css    التنسيقات + الثيمات الخمسة + مكوّنات الواجهات المصغّرة
assets/script.js    تبديل الثيم، القائمة، الظهور التدريجي، التنقل السلس
```

موقع ثابت بلا أي أدوات بناء — يكفي فتح `index.html` في المتصفح، أو:

```bash
python3 -m http.server 8000
```

## إمكانية الوصول

- دعم كامل للاتجاه من اليمين لليسار عبر الخصائص المنطقية (`inset-inline`, `padding-inline-start`).
- احترام `prefers-reduced-motion` بتعطيل الحركات.
- حالات تركيز واضحة، وسمات `aria` على القائمة ومبدّل الثيمات.
