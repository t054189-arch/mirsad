# مرصاد · MIRSAAD

منصة تجريبية لإدارة وتحليل بيانات فحص المنشآت. موقع ثابت من ثلاثة ملفات، يعمل بفتح `index.html` مباشرة في المتصفح — بدون تثبيت أو خادم أو خطوة بناء.

A static demo site for structural inspection management. Three files, no build step.

| الملف | المحتوى |
| --- | --- |
| `index.html` | الصفحة |
| `app.css` | التنسيقات |
| `app.js` | التطبيق بالكامل |

## التشغيل

افتح `index.html` في أي متصفح حديث، مع إبقاء الملفات الثلاثة في المجلد نفسه.

للنشر على الإنترنت: ارفع الملفات الثلاثة إلى أي استضافة ثابتة (GitHub Pages أو Netlify أو Vercel أو استضافة عادية عبر FTP).

## ملاحظة

هذا عرض تجريبي: لا يوجد خادم ولا قاعدة بيانات ولا ذكاء اصطناعي خلفه. جميع المنشآت والفحوصات والنتائج مُتخيَّلة، والقرارات تُحفظ في متصفحك وحده.
